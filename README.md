
The Warehouse Live Arrival Index is a C++ based Data Structures and Algorithms (DSA) project designed to efficiently track incoming packages in a warehouse.
It maintains received package IDs as sorted, non-overlapping intervals instead of storing every package ID individually. This helps identify received packages, detect missing package ranges, and perform efficient range-based queries.
Programming Language: C++
Data Structure: STL Map (Balanced Binary Search Tree)
Libraries: iostream, map, algorithm, iterator
Concepts: Interval Management, Searching, Sorting, Range Queries, Duplicate Detection.

This project was developed as part of a Data Structures and Algorithms (DSA) learning initiative, with contributions from team members.
